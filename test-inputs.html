insert mode on click

1. plain input

The baseline. This always worked.

2. autofocused input

Focused by the page on load, so clicking it fires NO focus event. Nothing was ever reported and the click did nothing.

3. input inside shadow DOM

document.activeElement returns the HOST, not the input.

4. input inside a same-origin iframe

document.activeElement returns the <iframe> element.

5. designMode iframe (rich-text editor)

How TinyMCE and friends work. designMode is on the INNER document.

6. a button — must NOT enter insert

The control case. Clicking this should leave the mode alone.
